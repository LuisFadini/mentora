# Documentação do projeto

## O que é?

Este projeto surgiu com o objetivo inicial de ser uma plataforma focada em questões do ENEM. Após discussões e evolução da ideia, o escopo foi ampliado para oferecer uma experiência mais completa de estudo.

Atualmente, a plataforma propõe:

- Disponibilização de questões do ENEM
- Inclusão de questões de outros vestibulares
- Disponibilização de conteúdos teóricos
- Um fórum para discussão e resolução de dúvidas

O objetivo é centralizar recursos de estudo em um único ambiente.

## Documentação de endpoints

Todos os endpoints da API devem ser documentados utilizando o padrão OpenAPI.

Além disso, a documentação deve ser mantida atualizada no arquivo [endpoints.md](endpoints.md).

## Roadmap

O planejamento, organização de tarefas e evolução do projeto estão disponíveis no GitHub Projects: [Roadmap](https://github.com/users/LuisFadini/projects/5/views/2)

## Estilo de código

Para garantir qualidade, organização e manutenibilidade, o projeto segue as seguintes diretrizes:

- Aplicação dos princípios SOLID
- Padronização de código utilizando ESLint
- Manutenção de consistência entre os módulos do sistema
